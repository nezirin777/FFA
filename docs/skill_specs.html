必殺技は戦術マスターのIDをそのまま sub_def/skills.py のクラス名に使う互換仕様です。IDを振り直さず、戦術の追加・変更時は戦術マスター、プレイヤー側・対人側の実装、資料をまとめて確認してください。

設定から戦闘までの経路

段階現行処理管理上の確認点
利用可能な戦術cgi_py/tac_change.py が現在職の job_ids と ms を検証する。現在の設定では他職も熟練度Lv60以上なら候補へ加える。reset_tactics_on_job_change={num(c['reset_tactics_on_job_change'])}。戦術変更のPOSTでも候補にないIDは拒否する。
選択の保存選択IDを chara.tactic_id へ保存する。0は「普通に戦う」。戦術IDは職業IDではない。データ移行・管理編集でも両者を混同しない。
プレイヤー側各ターンで tech_<tactic_id>.hissatu、通常攻撃後に tech_<tactic_id>.atowaza を実行する。クラスまたはメソッドが存在しない場合、run_skill() は何もせず続行する。
対人相手側各ターンで wtech_<tactic_id>.whissatu、後発で wtech_<tactic_id>.watowaza を実行する。下の対応表で実装名を確認する。クラスまたはメソッドが存在しない場合、run_skill() は何もせず続行する。
モンスター側special_skill_id から mons_<ID>.mons_waza と mons_atowaza を実行する。特殊率は各モンスターの special_rate を使う。
装飾品通常攻撃後に自分側は acstech_<effect_id>.acskouka、対人相手側は wacstech_<effect_id>.wacskouka を実行する。effect_id と special_rate は別の役割。前者は固有効果、後者は戦術必殺率への補正。

戦術必殺技の発動率

基本率 = floor(カルマ / 15) + 10 + 現職熟練度Lv 基本率は75で上限 → 装飾品 special_rate を加算 → 95で上限 発動判定 = 率 > random.randrange(乱数幅) 通常は戦術の activation_denominator を乱数幅として使う。

条件補正
発動率ラベルの既定値激高=60 / 高=80 / 中=100 / 低=120 / 超低=180 / 激低=200。activation_denominator がある戦術はその値を優先する。
幻影の城・異世界プレイヤー側の率を3分の1へ切り捨てる。
レジェンドプレイスプレイヤー側の率を2分の1へ切り捨てる。
リミットブレイク自HPが最大HPの10%未満かつ4分の2の抽選に通ると、率へ999を加算する。
対人相手相手のカルマ・現職熟練度・装飾品special_rateから別に計算する。

乱数幅がDで率が0〜Dの範囲なら、おおよその発動確率は率/Dです。実際には上限・モード減衰・リミットブレイク・効果側の追加抽選があるため、説明文だけから最終ダメージや発動回数を判断しないでください。
